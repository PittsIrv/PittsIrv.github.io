## Overview

A modern task management application built with Next.js and Firebase, featuring real-time collaboration and an intuitive drag-and-drop interface.

## Features

- **Drag and Drop**: Intuitive task organization with smooth animations
- **Real-time Sync**: Changes appear instantly for all collaborators
- **Cloud Storage**: Your tasks are safely stored and accessible anywhere
- **Smart Filters**: Quickly find tasks by tags, priority, or due date
- **Dark Mode**: Easy on the eyes for late-night productivity sessions

## Technical Highlights

- Built with TypeScript for type safety
- Uses Next.js for optimal performance
- Firebase for real-time database and authentication
- Responsive design works on all devices
- Optimistic UI updates for snappy user experience

## Challenges Solved

One of the biggest challenges was implementing smooth drag-and-drop while maintaining real-time sync across multiple clients. The solution involved optimistic updates on the client side with conflict resolution on the backend.

## What I Learned

This project taught me a lot about real-time data synchronization, state management in React, and the importance of optimistic UI updates for perceived performance.
