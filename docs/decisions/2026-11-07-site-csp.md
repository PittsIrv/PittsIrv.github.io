# Site-wide Content-Security-Policy (T-0037)

Goal: defence in depth for the site editor's token. It lives in this origin's browser storage, so every page should refuse scripts from anywhere but this site. Measure: 0 CSP violations and 0 external script origins on every built page, with the MeeTwo chat working end to end.

## What changed
- `src/layouts/Layout.astro` sets a meta CSP on every page:
  `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self' <MeeTwo API origin>; object-src 'none'; base-uri 'self'; form-action 'self'`.
  The MeeTwo API origin comes from `PUBLIC_STANDIN_URL` at build time. With no API configured, connect-src is `'self'` only.
- `astro.config.mjs` makes Astro emit every stylesheet and script as a file: `build.inlineStylesheets: 'never'` and `vite.build.assetsInlineLimit: 0`. The policy therefore needs no `'unsafe-inline'`, no hashes and no `'unsafe-eval'`.
  - The three scripts that were inline are now files: the MeeTwo launcher, the chat, and the poker-variant link opener.
  - The page `<style>` blocks are now files.
  - JSON-LD blocks stay inline; they are data, and CSP does not apply to them.
- `/admin` keeps its own, stricter policy. It is a static file and does not use the layout.

## Check (local production build)
- **Console.** All 9 sitemap pages and a redirect page show no console error, no CSP violation and no external request at 1280 and 375 px, apart from the MeeTwo API.
  - `/admin` shows one blocked request: Sveltia's version check against unpkg. This block is intended, and Sveltia has no setting to turn the check off.
  - An unknown path gets GitHub's own 404 page, which has its own policy and no scripts.
- **Chat.** The site was built with a local stand-in for the API origin. It forwards to the real MeeTwo API exactly as the live origin does; the API's CORS rule admits only `https://pittsirv.github.io`.
  - On /meetwo, a question gets an answer.
  - The floating panel opens at 375 px and keeps the conversation.
  - No console errors.
- **Visible change.** Full-page screenshots before and after are pixel-identical on every page at both widths, with animations frozen. The exceptions:
  - The Quotes section, shuffled at each build, was excluded.
  - The poker-variant order on /personal differs between any two builds, this one included: the collection is read in file-listing order. It is the same set of 12 variants; this predates the change.
- **Variant links.** `/personal#game-auction` still opens that variant.
- **Deploy checks.** `npx tsc --noEmit` and `npm run build` pass.

## Limits
- A meta CSP cannot set `frame-ancestors`, `report-uri` or `sandbox`. GitHub Pages cannot send headers, so framing by other sites is not blocked.
- The four redirect pages (`/academic`, `/poker`, `/writing`, `/misc`) are generated by Astro without the layout and carry no policy. Each holds only a meta refresh and a link, with no script, style or font.

## Small decisions (Claude)
- **`style-src 'self'` without `'unsafe-inline'`.** No element has a `style` attribute. Styles that scripts set through the DOM (the MeeTwo panel, the editor) are not affected by CSP.
- **No hashes.** Emitting files is simpler than keeping hashes in step with Astro's output, and it survives content edits.
